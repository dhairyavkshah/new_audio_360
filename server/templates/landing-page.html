Pure native Android music player - offline & device-local

This is a Native Android Project

This app is built as a pure native Android application using Kotlin and the Android SDK. It cannot be previewed in a web browser.

To run this app, you need to build an APK and install it on an Android device or emulator.

How to Build

  1. 1 Clone the repository to your local machine or use GitHub Actions
  2. 2 Open the android/ folder in Android Studio
  3. 3 Build the APK using Gradle:
# Navigate to android directory
cd android

# Build debug APK
./gradlew assembleDebug

# Or build release APK
./gradlew assembleRelease

GitHub Actions

This project includes a GitHub workflow for automated builds. Push to the repository and GitHub Actions will automatically build the APK.

Check github-workflow-build-android.yml for the workflow configuration.

Development Note

Web preview is not available for native Android apps. Use Android Studio or the command line with Gradle to build and test the application.
