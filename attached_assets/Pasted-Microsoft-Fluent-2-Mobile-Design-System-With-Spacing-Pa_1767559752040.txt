Microsoft Fluent 2 – Mobile Design System
(With Spacing & Padding Principles – Complete)
1. Fluent 2 Core Philosophy (Recap)

Fluent 2 prioritizes:

Breathing space

Predictable rhythm

Visual calm at scale

Spacing is not decoration — it creates hierarchy.

2. The Fluent 2 Spacing System (Foundation)
4px Base Unit (MANDATORY)

All spacing, padding, margin, sizing must be multiples of 4px.

Spacing Scale (Standard Tokens)
Token	Value	Usage
size-1	4px	Icon gaps, micro spacing
size-2	8px	Inline elements
size-3	12px	Compact padding
size-4	16px	Standard padding
size-5	20px	Comfortable padding
size-6	24px	Section spacing
size-7	32px	Major separation
size-8	40px	Page rhythm
size-9	48px	Large structural gaps
3. Screen-Level Padding Rules
Horizontal Padding

Minimum: 16px

Recommended: 20px

Never exceed: 24px

Vertical Padding

Top safe area respected

First component from top bar: 16–24px

4. Section & Content Spacing
Between Sections

24–32px

Never less than 24px

Between Related Components

12–16px

Between Unrelated Components

24px+

Fluent 2 relies on space instead of dividers.

5. Top App Bar Spacing
Height

Standard: 56px

Internal Padding

Left / Right: 16px

Icon–text gap: 8px

Title baseline centered vertically

Spacing Below Top Bar

First content block: 16–24px

6. Secondary Bars / Filter Bars

Height: 48px

Horizontal padding: 16px

Spacing below: 16px

7. Bottom Navigation Bar
Height

64px

Icon & Label Spacing

Item internal padding: 8–12px

Music App Rule

Mini player floats ABOVE bottom bar

Gap between mini player & nav bar: 8px

16. Music Player – Spacing Specifics
Mini Player

Height: 64–72px

Internal padding: 12px

Full Player

Controls grouped within 16px cluster

Playback Controls

17. Dialogs & Bottom Sheets
Bottom Sheet Padding

Horizontal: 16–20px

Top spacing before content: 16px

Dialog Button Spacing

Buttons separated by 12px

Content → actions: 24px

18. Motion + Spacing Relationship

Motion never collapses spacing

Components fade/slide without overlapping

Spatial consistency preserved during animation

19. Accessibility & Touch

Minimum touch target: 48px

Maintain spacing even when scaled

Avoid compressed layouts in accessibility modes

20. Golden Fluent 2 Spacing Rules

✅ Space replaces borders
✅ Rhythm > density
✅ Consistency beats creativity
❌ Never eyeball spacing
❌ Never mix spacing systems

Fluent 2 Mental Model (Final)

If something feels crowded, it is wrong — even if it fits.
Fluent 2 UI should feel like a calm, confident conversation.
