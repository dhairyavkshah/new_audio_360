Studio Mode – Simple User Story Requirements
1. Entry & Purpose

As a user, I want to switch to Studio Mode from the music player,
so that I can work with audio instead of just listening.

2. Audio Input

As a user, I want to load audio from my device (songs, voice recordings, clips),
so that I can edit or enhance them.

As a user, I want to record fresh audio using my microphone,
so that I can create new content inside the app.

3. Basic Editing

As a user, I want to trim, cut, split, and merge audio,
so that I can clean and arrange my sound easily.

As a user, I want to undo and redo changes,
so that I can experiment without fear.

4. Multi-Track (Simple)

As a user, I want to place multiple audio tracks on a simple timeline,
so that I can layer music, vocals, or sounds.

As a user, I want to mute, solo, or adjust volume per track,
so that I can control how everything sounds together.

5. Effects & Enhancements

As a user, I want to apply basic effects (like EQ, reverb, bass, clarity),
so that my audio sounds better without complexity.

As a user, I want presets instead of advanced controls,
so that studio usage stays simple and fast.

6. Karaoke / Voice Practice (Optional but Planned)

As a user, I want to remove or reduce vocals from songs (if possible),
so that I can sing or practice over music.

As a user, I want to record my voice over a track,
so that I can practice, rehearse, or create covers.

7. Preview & Playback

As a user, I want to preview my edits instantly,
so that I can hear changes in real time.

As a user, I want playback controls similar to the music player,
so that Studio Mode feels familiar.

8. Save & Export

As a user, I want to save my studio projects locally,
so that I can continue later without internet.

As a user, I want to export final audio in common formats (MP3, WAV),
so that I can share or use it outside the app.

9. Non-Goals (Important)

As a user, I do NOT want professional DAW-level complexity,
so that the app remains lightweight and beginner-friendly.

As a user, I expect Studio Mode to feel like an extension of the music player,
not a separate complicated tool.

10. Philosophy

As a user, I want Studio Mode to feel calm, minimal, and creative,
so that I focus on expression, not tools.
